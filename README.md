## 🚀 快速开始

### 一键测试命令

```bash
curl -fsSL https://raw.githubusercontent.com/weiruankeji2025/weiruan-vps/main/vps_test.sh | sudo bash
```

或者使用 wget：

```bash
wget -qO- https://raw.githubusercontent.com/weiruankeji2025/weiruan-vps/main/vps_test.sh | sudo bash
```

### 手动安装

```bash
# 克隆仓库
git clone https://github.com/weiruankeji2025/weiruan-vps.git
cd weiruan-vps

# 添加执行权限
chmod +x vps_test.sh

# 运行测试
sudo ./vps_test.sh
```

## 📋 测试项目

### 1. 📊 系统信息检测
- 操作系统版本

### 4. 💿 磁盘 I/O 性能测试
- **写入速度测试** - 测试磁盘顺序写入性能
- **读取速度测试** - 测试磁盘顺序读取性能
- 自动识别 SSD/HDD 类型
- 性能等级评估

### 5. 🌐 网络性能测试
- **公网IP信息** - 获取服务器公网IP

- **延迟测试** - 测试到国内外主要节点的网络延迟

  - 阿里云
  - Google
- **下载速度测试** - 测试国际节点下载速度

### 6. 📋 测试总结
- 测试总耗时统计
- 完整性能评估
- Markdown 格式报告生成

## 📖 使用说明

### 系统要求

- **操作系统**: Linux (支持 Ubuntu, Debian, CentOS, RHEL 等)
- **权限**: 需要 root 权限
- **网络**: 需要网络连接以进行网络性能测试

### 依赖项

工具会自动检测并安装以下依赖：
- `curl` - 网络请求工具
- `wget` - 文件下载工具
- `bc` - 数学计算工具
- `sysstat` - 系统性能监控工具

### 运行步骤

1. **下载脚本**
   ```bash
   curl -O https://raw.githubusercontent.com/weiruankeji2025/weiruan-vps/main/vps_test.sh
   ```

2. **添加执行权限**
   ```bash
   chmod +x vps_test.sh
   ```

3. **运行测试**
   ```bash
   sudo ./vps_test.sh
   ```

4. **查看报告**
   - 测试完成后会在当前目录生成 `vps_test_report_YYYYMMDD_HHMMSS.md` 文件
   - 终端会直接显示完整的测试报告

## 🐛 故障排除

### 常见问题

**Q: 提示 "请使用 root 权限运行此脚本"**
```bash
# 使用 sudo 运行
sudo ./vps_test.sh
```

**Q: 网络测试失败**
- 检查服务器是否能正常访问互联网
- 某些VPS可能限制了ICMP协议，导致ping测试失败

**Q: 依赖安装失败**
```bash
# 手动安装依赖
# Ubuntu/Debian:
apt-get update
apt-get install -y curl wget bc sysstat

# CentOS/RHEL:
yum install -y curl wget bc sysstat
```

**Q: 磁盘测试速度异常**
- 确保 /tmp 目录有足够的空间（至少2GB）
- 某些VPS可能限制了磁盘I/O性能

## 📊 性能参考标准

### CPU 性能
- **优秀**: 单核 < 10s, 多核 < 5s
- **良好**: 单核 < 20s, 多核 < 10s
- **一般**: 其他情况

### 内存性能
- **优秀**: > 1000 MB/s
- **良好**: > 500 MB/s
- **一般**: < 500 MB/s

### 磁盘 I/O
- **优秀 (SSD)**: > 500 MB/s
- **良好**: > 100 MB/s
- **一般 (HDD)**: < 100 MB/s

### 网络延迟
- **优秀**: < 50ms
- **良好**: < 150ms
- **一般**: > 150ms

### 下载速度
- **优秀**: > 10 MB/s
- **良好**: > 5 MB/s
- **一般**: < 5 MB/s
